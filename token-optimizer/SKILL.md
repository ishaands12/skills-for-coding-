# Token Optimizer Skill

Actively enforce token efficiency — not just advice, but real actions: audit the
current conversation, generate handoff summaries, batch prompts, and flag waste.

---

## Step 1: Read the Principles Reference

Always read the full principles file before doing anything:

```bash
cat <skill_path>/references/principles.md
```

This contains the 8 rules, violation severity table, and replacement strategies.

---

## Step 2: Detect the Mode

Determine what the user needs based on their message:

| User says | Mode |
|-----------|------|
| "summarize this chat", "start fresh", "new chat", "handoff" | **Summarize** |
| "batch these", "combine these", pastes multiple questions | **Batch** |
| "audit", "optimize", "reduce tokens", "check this chat" | **Audit** |
| "/token-optimizer" with no extra context | **Audit** (default) |
| Ongoing conversation where a violation is detected | **Inline Warning** |

## Mode A: Audit

Analyze the current conversation and score it against the 8 principles.

### What to check:

1. **Message count** — count assistant + user turns in this conversation
2. **Micro-prompts** — are there recent messages under ~10 words with no batching?
3. **Repeated uploads** — has the same file/document been referenced or uploaded more than once?
4. **Feature flags** — ask the user which Claude features are currently enabled
5. **Question batching** — are there sequences of single questions that could have been combined?
6. **Session pattern** — did the user mention starting this session hours ago / is this clearly a long session?

### Output format:

```
## Token Usage Audit

**Conversation health:** [Good / At Risk / Heavy]
**Estimated message count:** ~N turns

### Issues Found

🔴 HIGH  — [violation description]
🟡 MED   — [violation description]
🟢 LOW   — [violation description]

### Immediate Actions

1. [Most impactful thing to do right now]
2. [Second most impactful]
3. [Optional improvement]

**Recommendation:** [one sentence — e.g. "Start a fresh chat now and use the summary below."]
```

If the conversation is under 10 messages and no violations found:
```
## Token Usage Audit

**Status:** Clean — no significant waste detected (~N turns)

Keep an eye on:
- [one relevant principle to watch for given the conversation topic]
```

## Mode B: Summarize (Context Handoff)

Generate a compact, paste-ready summary the user can drop into a new chat.

### The summary must contain:

1. **Project/task context** — what is being built or worked on, in 2–3 sentences
2. **Key decisions made** — bullet list of choices locked in (tech stack, approach, constraints)
3. **Current state** — what exists/works right now
4. **Active files or locations** — paths or filenames that matter
5. **Next step** — exactly what to do next (the first thing Claude should tackle in the new chat)
6. **User preferences** — any style/format/behavior preferences mentioned in this chat

### Output format:

````
## Context Handoff — Paste This Into Your New Chat

---

**Project:** [name or one-line description]

**What we're building:**
[2–3 sentences]

**Decisions locked in:**
- [decision 1]
- [decision 2]
- [decision 3]

**Current state:**
[what exists, what's working, what's partial]

**Key files:**
- `path/to/file` — [what it does]

**Immediately continue with:**
[exact next task, phrased as a prompt Claude can act on directly]

**Preferences to keep:**
- [tone, format, language, framework preferences from this chat]

---
*Generated by token-optimizer. Start a fresh chat, paste this at the top, and continue.*
````

**After outputting the summary**, tell the user:
> This chat is ready to close. Open a new chat, paste the block above, and continue from there. You'll save [estimated N] messages worth of context overhead.

## Mode C: Batch

Take multiple questions, tasks, or edits the user has listed and combine them into one optimized, dense prompt.

### Process:

1. Identify all the separate items (questions, edits, review requests, tasks)
2. Group related items together
3. Rewrite as a single coherent multi-part prompt with clear numbered structure
4. Estimate how many context loads this saves vs sending separately

### Output format:

```
## Batched Prompt

Here's your [N] items combined into one turn:

---

[The combined prompt, well-structured with numbered sections]

---

**Saves:** ~[N-1] full context loads vs sending separately.
Copy the block above and send it as one message.
```

## Mode D: Inline Warning (Passive Monitoring)

If you notice a violation mid-conversation **without** the user asking for an audit, surface a brief warning rather than a full audit report. Keep it short — one line + one action.

Examples:

> ⚡ **Token tip:** This is message ~18 — consider summarizing and starting a fresh chat soon. Run `/token-optimizer summarize` when ready.

> ⚡ **Token tip:** You just sent 4 micro-prompts in a row. Batch your next few edits into one message to save 3 context loads.

> ⚡ **Token tip:** Extended thinking is on — turn it off for this task since you're working with your own content, not research.

Only surface an inline warning when the violation is **active and ongoing** — not as a general reminder. Do not repeat the same warning twice in one conversation.

---

## Key Reminders

- Always read the reference file first — every audit must be grounded in the 8 principles
- In Summarize mode, make the handoff summary **complete enough to stand alone** — the user must be able to paste it cold into a new chat and have full context
- In Batch mode, do not just list the items back — actually **rewrite them** as a single coherent prompt
- Never be preachy. One clear action per finding. No walls of advice.
- The goal is fewer tokens spent, not perfect compliance. Prioritize the highest-impact changes.
