# Skills for Coding 🚀

Welcome to the **Skills for Coding** repository! This is a centralized hub for modular, production-grade AI skills and agentic workflows designed to enhance productivity and automate complex development tasks.

## 🌟 Overview

This repository provides a collection of specialized "skills"—instructions, scripts, and resources that empower AI agents to handle intricate software engineering challenges. From architectural reviews to automated project scaffolding, these skills are built to be robust, reusable, and easy to integrate into any AI-driven development environment.

## 🛠️ Key Skills & Capabilities

Our growing library includes:

- **🏗️ Software Architecture**: Professional review skills (`architect-review`) to ensure modern design patterns and scalability.
- **🚀 Project Scaffolding**: Modular initialization tools (`new-project`, `gsd`) for rapid, phase-based development.
- **🎨 Design & Frontend**: Advanced UI/UX skills (`frontend-design`, `canvas-design`) to create visually stunning and functional interfaces.
- **🤖 Automation & Workflow**: Specialized n8n integrations, Slack automation (`slack-gif-creator`), and web scraping (`firecrawl-scraper`).
- **📊 Data & Documentation**: Utilities for handling complex formats (`docx`, `pdf`, `xlsx`) and professional doc co-authoring tools.

## 🌱 Evergreen Repository

This is an **evergreen repository**. I am committed to continuously expanding this collection by identifying, developing, and integrating new useful skills as the AI coding landscape evolves. Whether it's a new framework support or a novel agentic workflow, you'll find it here as I discover what truly works in the field.
